# DivaShow：整局流程、皮肤、技能、高光和排行榜

给 Diva 加上像 FPS 游戏一样的一整局：

```
选涂装 → Eva 的赛车式开场（航拍、火箭、俯冲、绕大象一圈机甲逐个点亮、3·2·1 GO；大象出场时加我们的出场音效）
→ 游戏（技能横幅、画中画特写、连击、大招） → 结束动画 → 本局高光回放 → 结算卡片和排行榜 → 再来一局
```

开场部分全部用 Eva 的 `DivaIntro`（`Assets/DivaGame/Runtime/DivaIntro.cs`），这里只在她的俯冲落到起跑线、开始绕大象的那一刻（`DivaIntro.SwoopEnd`，现在是 9 秒）放出场音效的重击；她改时间轴时会自动跟上。
场景里没有 `DivaIntro` 时，才用这里自带的机甲启动特写和倒数代替。

界面默认是英文，右上角 **EN 中文** 按钮（或 L 键）切换中文。名字和标志都是我们自己的，只参考 Overwatch 的感觉：没有用 "Play of the Game"、"Nerf This"，也没有用 MEKA 和兔子 logo。

## 怎么用

`Assets/DigiPhant/Scenes/Diva.unity` 已经装好了（场景里多了一个 **Diva Show** 物体），按 Play 就从选涂装开始。

- 别的场景：打开场景，点菜单 **Diva > Show > Install Show in Open Scene**。项目里没有 `Assets/TextMesh Pro` 时会先导入 TextMesh Pro 基础资源，导入后再点一次。
- 想看原来的调试面板（摄像头预览、Test controls、Get ready 等）：按 **F1** 或右上角 **SETUP**。
- 不想要这一套：把 Diva Show 物体关掉，场景回到原来的样子。

## 单人游戏

默认是单人：一个人同时控制移动、转向、喷水、喝水和大招（`DivaDemo` 的 Try alone 新增了 **All** 选项）。选涂装界面右边可以切到 **3 PLAYERS**（原来的三人分工）。

| 动作 | 手势 | 键盘（测试用） |
| --- | --- | --- |
| 前进 | 双臂举起上下摆 | F1 打开调试面板，用 Test controls 的滑块 |
| 转向 | 双手并拢和身体一起往左/右倾 | 同上 |
| 瞄准 | 举起一只手；喷水时双手一起往一边推 | 同上 |
| 喷水 | 双手张开往前推 | 同上（勾 Spray water） |
| 喝水 / 泡泡 | 双手合在嘴边 | 同上（勾 Drink / refill） |
| **大招 / 确认** | **双手举过头顶停 0.8 秒** | U（大招）/ 回车（确认） |
| 选涂装 | 举左手 / 右手切换 | ← → |
| 跳过过场 | 双手举过头顶 | 回车 / Esc |

一个人做全部动作时，摆臂进入喷水或喝水姿势的那一下不会让大象往前走，喝水时也不会转向。大招手势要求双手都高过头顶并停住，摆臂经过头顶只有一瞬间，不会误触发。

## 每个阶段

| 阶段 | 内容 |
| --- | --- |
| 选涂装 | 按 Play 后第一个画面。大象站在发光的圆台上，镜头在周围最空的一段弧里来回转（会避开路边道具），鼠标拖动可以自己转。四款涂装：经典糖果、紫晶夜色、青瓷晴空、樱桃校园。右上角是摄像头画面，所有人入镜后自动开始 10 秒校准（原来的 Get ready） |
| Eva 的开场 | 选好后播放 Eva 的 `DivaIntro`（约 20 秒，机甲点亮时已经是选好的涂装）。9 秒大象出场时放"嘚嘚——嘚嘚——轰"（重击对准开始绕圈那一刻）。双手举高、回车或 Esc 跳到倒数。她的 GO 出现时开始计时，并重置分数、靶子和任务 |
| （没有 Eva 开场时） | 用这里自己的机甲启动特写和 3·2·1，选涂装界面放出场音效配烟火 |
| 游戏 | 左上分数和用时，左边任务清单，右上事件栏，底部技能栏（大招圆环在中间），靶子上的锁定圈，命中 +10 飘字，连击数，跑满速时的速度线 |
| 结束 | 四个任务全部完成（或超时）时：慢动作，大象扬鼻长鸣（模型自带的 trumpet 动画），彩带和烟花，横幅 COURSE COMPLETE 和用时、分数 |
| 本局高光 | 自动找最精彩的 8 秒，用录下来的数据重演（不是录屏），换电影镜头；关键一击放慢，从被打中的靶子后面看回大象。可以跳过 |
| 结算 | 队名（自动起名，换语言时一起换）、分数、名次和新纪录、玩家卡片和称号、排行榜前 8 名。双手举高或回车再来一局 |

## 光影（DivaLook）

`Diva Show` 物体上的 `DivaLook` 在运行时叠一层，不改 Eva 的灯光、天空和 Diva Post FX，关掉这个组件就是她原来的样子：

| 项目 | 做法 |
| --- | --- |
| Bloom | 阈值提高到 1.15，只有霓虹、发光部件和特效会晕开，亮色地面不再一片发白；高质量滤波 |
| 调色 | 对比 +20，饱和 +10，暗部偏冷紫、亮部偏暖，一点暖白平衡，柔和暗角 |
| 明暗反差 | 环境光 ×0.85，太阳光 ×1.08；SSAO 稍强（强度 0.6，半径 0.4，在 `Assets/Settings/PC_Renderer.asset`） |
| 轮廓光 | 一盏只照大象和机甲的冷色光（灯光图层 7），跟着镜头始终从后上方打，把主角从背景里分出来 |
| 反射 | 覆盖整条赛道的反射探针，开局渲染一次，机甲的金属和光面反射糖果小镇 |
| 抗锯齿 | 主摄像机 SMAA（高） |
| 过场电影感 | 选涂装、Eva 开场绕圈、大招、结束、高光回放、结算时：景深对焦大象（85mm f/4）和一点胶片颗粒；大招爆开、冲刺、连击时短暂的色差和 Bloom 加强 |

## 摄像头画面

原来的摄像头预览在调试面板收起时，会变成右上角的浮动窗口，盖住界面。现在由 Diva Show 画：选涂装时在右上角（大一点，方便校准时看到自己），游戏中缩小放在左下角。F1 打开调试面板时照常画在面板里。

## 技能

| 技能 | 触发 | 表现 |
| --- | --- | --- |
| BOOSTER RUSH 推进冲刺 | 接近最高速持续 1 秒（8 秒冷却） | 横幅、画中画拍推进器、速度线、视野拉宽 |
| TRUNK CANNON 象鼻水炮 | 开始喷水（横幅 8 秒内只出一次） | 横幅、画中画拍鼻尖水枪 |
| BUBBLE REFILL 泡泡补给 | 开始喝水（6 秒冷却） | 横幅、画中画拍泡泡炮 |
| TRIPLE SPLASH 三连击 / SPLASH STORM 水花风暴 | 2.5 秒内连续命中 3 / 5 个 | 横幅、+30 / +60 奖励分 |
| TASK COMPLETE 任务完成 | Eva 的四个课程任务 | 横幅、大招充能 +25% |
| MEGA BUBBLE 超级泡泡（大招） | 充满后双手举过头顶（或 U） | 全屏过场：正面特写，彩虹巨型泡泡从背上长出来往前飞，爆开时慢动作，打倒前方 18 米内所有竖着的靶子（每个 +10 奖励分） |

大招充能：每命中一个靶子 12%，每完成一个任务 25%，每走 1 米 1.2%。普通技能用画中画小窗特写，不切走主镜头；只有大招全屏。

分数：Eva 的 `DivaGameManager` 照常判定打靶和任务（这里不改她的规则），界面显示的分数 = 她的分数 + 连击和大招的奖励分。

## 设置（选中 Diva Show 物体）

| 字段 | 说明 |
| --- | --- |
| Single Player | 单人全部控制；关掉是三人分工 |
| Time Limit | 每局秒数，0 = 不限时（全部任务完成才结束） |
| Highlight Seconds | 高光回放长度 |
| Charge Per Hit / Task / Metre | 大招充能速度 |
| Ult Range | 大招打靶范围 |
| Race Intro | Eva 的 `DivaIntro`（安装时自动填）。空着就用这里自己的启动和倒数 |
| Entrance Music | 出场音效，可以换成任何有授权的音频 |
| Hide Debug Panels | 游戏时隐藏 Eva 的 IMGUI HUD 和调试面板 |

## 字体

英文用项目里的 Saira（OFL 授权）。中文用系统字体做后备（Mac 上是苹方），所以仓库里不放中文字体文件。没有中文系统字体的电脑上，中文会显示成方框。

## 测试情况
