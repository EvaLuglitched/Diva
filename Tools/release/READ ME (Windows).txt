Diva for Windows (10 or 11, 64-bit)
Team Diva: Eva, Carl, Vicky · DesComp Project 2 (DigiPhant) · https://github.com/EvaLuglitched/Diva

PLAY
1. Unzip the whole folder first (do not run it from inside the zip). Keep Diva.exe, Diva_Data and DivaTracking together.
2. Run Diva.exe. If Windows SmartScreen appears: More info > Run anyway (the game has no publisher certificate).
3. The camera starts by itself: the body tracking (MediaPipe) is built in, no Python or setup needed, and nothing is
   uploaded. If Windows asks whether Diva may use the camera, allow it. The very first camera start takes about
   20 s (it prepares the tracking once); after that a few seconds.
   If the picture stays dark: Settings > Privacy & security > Camera > turn on "Camera access" and
   "Let desktop apps access your camera", close other apps that use the camera (Teams, Zoom), then click Retry.
   Wrong camera (a USB webcam, a virtual camera or a face-login camera)? Press C on the camera check page, or
   F1 > Next camera at any time, until you see yourself. Diva remembers the camera for next time.
   If the tracking ever stops, it starts again by itself.
The keyboard works at any time, with or without the camera.

CONTROLS (one player does everything; 3 PLAYERS splits them left to right)
  Walk / run ........ pump both arms up and down            keyboard W
  Turn .............. tilt your shoulders or head            A / D
  Aim the trunk ..... raise one arm                          U / I
  Spray water ....... push both open hands forward (hold)    Space
  Eat, drink, refill  thumbs-up for 0.4 s                    F
  MEGA BUBBLE ....... both hands above your head 0.8 s       E
  Menus ............. raise one arm = next skin, both hands up = start    arrows, Enter
  F1 setup panel · F2 frame rate · Esc skip · C next camera (camera check page)

Tested on Windows Server 2025 (GitHub Actions, no webcam): the game, a keyboard race, the tracking start-up,
the models and switching cameras. Live camera play on a Windows PC: not yet tested by the team.
